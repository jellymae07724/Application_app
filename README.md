# Application_app
🌐 Streamlit Portfolio App
This is a simple personal portfolio web application built using Streamlit. It showcases my home page, skills, projects, and provides a way to contact me.

📌 Features
🏠 Home Page
•	Introduction about me 
•	Overview of the portfolio 
•	Welcome message for visitors 

🧑💻 Skills Page
Displays my:
•	Technical Skills (Python, Web Development, UI/UX) 
•	Soft Skills (Problem Solving, Teamwork, Critical Thinking) 
•	Learning Goals 
•	Interactive fun fact button

📁 Projects Page
Includes a Calculator App with:
•	Addition 
•	Subtraction 
•	Multiplication 
•	Division 
•	Power 
•	Square Root 

📞 Contact Page
Allows users to:
•	Enter name, email, and message 
•	Send a message (basic validation) 
•	View social media links
